# Product audit

## Brutal finding

An AI remittance interface is worthless if the model itself is treated as the control plane. Models misread names, retries happen, rates expire, and wallet mistakes are irreversible. The product only earns trust when the agent is deliberately weaker than the sender-owned policy.

## Locked direction

Kinferry is not another wallet or generic payment chatbot. It is a constrained family-transfer rail: recipient-owned verification, on-chain authority limits, quote expiry, duplicate resistance, and one execution path for manual and scheduled payments.

## Business model

- API and dashboard subscription for wallets, payroll platforms, and licensed remittance operators
- Usage fee per guarded transfer attempt, including blocked attempts that produce auditable evidence
- Enterprise policy templates, support tooling, and corridor analytics

## Defensibility

The moat is the evidence graph linking recipient confirmation, policy state, quote provenance, dedupe fingerprints, and settlement references. The UI is replaceable; the trustworthy control history is not.

## Remaining risks

Regulatory scope, off-ramp partnerships, sanctions screening, key management, oracle quality, and smart-contract audit remain mandatory before real-money launch.
